
# LISA : Local Intelligent System Agent

- LISA is designed for users who want to manage their system through natural communication language.

- Currently LISA is trained only for english language.

- Primary operation of LISA is through "voice" and it also has "text" input method.


## While development:

- LISA will be first designed for text input only.

- It will be checked for every usage applications.

- If all the tests passed, we will introduce voice input processing.


## Tech-Stack:

1. For text input:
    - Terminal/CLI

2. For LLM:
    - OLLAMA
    - QWEN3.5:4b

3. Others:
    - MoE (Mixture of Experts)
    - JEV for expert routing
